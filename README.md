# 3D Flip Login & Signup Form

A modern and responsive Login & Signup interface built with **HTML, CSS and JavaScript**.

The form uses a smooth **3D flip animation** to switch between the Login and Registration views.  
The design combines soft shadows, depth effects and neumorphic styling to create a clean 3D appearance.

## Preview

### Login
The front side contains the login form with:

- Username field
- Password field
- Remember me switch
- Forgot password link
- Password visibility option
- Sign In button

### Sign Up
Clicking **Sign Up** rotates the complete form and reveals the registration page on the back.

The registration form includes:

- Username
- Email address
- Password
- Terms & Conditions checkbox
- Create Account button

Clicking **Sign In** rotates the form back to the login page.

## Features

- Smooth 3D flip animation
